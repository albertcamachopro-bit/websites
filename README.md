# Mockups web para clientes

Tres demos estáticas en HTML, CSS y JavaScript para presentar propuestas de páginas web:

- Restaurante de una hoja con menú, QR, mapa y contacto por WhatsApp.
- SPA de tres hojas: inicio, agenda de citas y contacto.
- Tienda online de cinco hojas: acceso, home, catálogo, carrito y contacto.

Abrir `index.html` para ver el menú principal de presentación.
